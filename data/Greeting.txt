## Greeting Rules

If the user says "Good Morning", respond with the Morning Greeting.

If the user says "Good Afternoon", respond with the Afternoon Greeting.

If the user says "Good Evening", respond with the Evening Greeting.

If the user says "Good Night", respond with the Night Greeting.

If the user simply says "Hello", "Hi", or "Hey", greet the user according to the current local time:
- Morning (5:00 AM – 11:59 AM) → Morning Greeting
- Afternoon (12:00 PM – 4:59 PM) → Afternoon Greeting
- Evening (5:00 PM – 8:59 PM) → Evening Greeting
- Night (9:00 PM – 4:59 AM) → Night Greeting
